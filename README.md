# Sri Sivani College of Engineering - Academic Portal

Official Academic Management Portal for **Sri Sivani College of Engineering (SSCE)**, Chilakapalem Jn, Srikakulam.
Approved by AICTE New Delhi, Affiliated to JNTUK Kakinada (CC-W6), Recognized under UGC 2(f) & 12(B), ISO 9001:2015 Certified.

---

## 🌟 Features Overview

- **Home Page**:
  - Hero introduction with college identity & video support.
  - College Information & Accreditations (JNTUK CC-W6, AICTE, UGC, ISO).
  - Campus Photo Gallery (Main Building, Gateway, Academic Quadrangle, Campus Avenue).
  - September 15 National Engineering Day Commemorative Banner.
- **Unified Dual-Tab Authentication**:
  - Student & Faculty login on a single portal page with remember me and demo quick-fill.
- **Student Portal**:
  - Academic Dashboard with overall Attendance %, Percentage %, SGPA, and Semester indicators.
  - Interactive SVG Subject Performance Visualizer.
  - My Profile (Official student enrollment record).
  - Attendance Tracker with circular gauge and subject-wise breakdown.
  - Subject Marks Statement for Semester 1 and Semester 2 (Internal/External breakdown).
  - Semester Results with instant **Download / Print Official Result Sheet as PDF**.
- **Faculty Portal**:
  - Class Dashboard with analytics (Average Attendance, Class Average Marks, Students Needing Attention).
  - Student Directory with real-time search, branch filtering, **Add Student**, **Edit Student**, and **Reset Password**.
  - Complete **360° Student Academic Profile**.
  - Single-Student **Marks Management** (Internal 40 + External 60 = 100, live Grade & SGPA calculation).
  - Single-Student **Attendance Management** (Total, Present, Absent, and Percentage override).
  - Official **Reports & Transcripts Generator** (Downloadable Result Sheets and Attendance Certificates).
  - Faculty Profile with appointment details and assigned teaching courses.
- **Data Persistence**:
  - 100% `localStorage` persistent prototype (Single device across browser sessions, reloads, and logouts).

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite 5, JavaScript (ES Modules)
- **Styling**: Vanilla CSS (Custom Design System with Cobalt Blue `#1d4ed8` theme)
- **Icons**: Lucide React
- **PDF Export**: jsPDF + html2canvas
- **Data Storage**: Client-side LocalStorage Engine

## 🚀 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# 3. Open in browser
http://localhost:5173/
```

### Production Build
